# school-lunch-bot

Telegram-бот, который заказывает ребёнку обед в школе, пока родитель спит.

**Задача.** Школа каждый вечер кидает в родительский чат многовариантный опрос «Заказ обеда на завтра» с пятью блюдами, срез в 9:00. Если не проголосовать, ребёнок без обеда. Голосовать руками каждый день надоело.

**Решение.** Юзербот на аккаунте родителя (Telethon) следит за темой форума, ловит новый опрос и присылает карточку с кнопками-блюдами ребёнку и родителю через обычного бота. Кто-то нажал «Заказать» → голос уходит в школьный опрос от имени родителя, оба получают отчёт. Передумал → переголосовывает. Никто ничего не нажал → в 8:30 уходит дефолт (суп + второе + гарнир), нелюбимый суп из списка `AVOID_DISHES` пропускается. По четвергам обед не нужен, бот молчит.

**Что внутри**
- `lunch.py` — основной сервис: две сессии Telethon (юзер и бот), слушатель темы форума, inline-клавиатура, напоминания 21:00 и 7:30, автозаказ, состояние в `state.json`, catch-up при старте.
- `login1.py`, `login2.py` — одноразовый вход юзер-сессии (телефон, код, 2FA).
- `config.example.py` — все настройки и секреты, копировать в `config.py`.

**Запуск**
```bash
python -m venv venv && venv/bin/pip install telethon
cp config.example.py /srv/lunch/config.py   # заполнить
python login1.py +7...   # затем login2.py <код> [2fa]
python lunch.py          # или systemd-юнит
```

**Грабли, на которых стоит бот**
- Bot API не может написать первым: оба адресата должны один раз нажать `/start`.
- Темы форума в Telethon читаются через `messages.GetForumTopics`, не через `channels`.
- Голос в чужом опросе отдаётся `messages.SendVote` от юзер-сессии, бот так не умеет.
